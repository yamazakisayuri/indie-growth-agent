# Growth Context

## Budget
Monthly marketing budget: ¥0

## Time
Available growth time: 3 hours/week

## Available
- App Store Connect
- App GA4 (when configured)
- Web GA4 (when configured)
- AdMob
- Growth Agent MCP
- Existing App Store metadata can be reviewed
- App Store keyword / metadata changes can be proposed
- App Store screenshot ideas can be drafted
- App Store metadata can be manually updated
- Web site can be manually edited (when Web channel exists)
- Existing App GA4 events can be analyzed
- Existing Web GA4 events can be analyzed when Web GA4 is configured

## Not available
- Paid ASO tools such as AppFollow or Sensor Tower
- Paid advertising
- Automatic App Store publish
- Automatic Web content publish

## Analytics constraints
- Prefer analyzing existing GA4 events before proposing new instrumentation.
- New analytics events or parameters are possible, but require implementation work and should only be proposed when the expected value justifies the cost.

## Execution
- Never publish or modify App Store metadata automatically.
- Never publish or modify Web site content automatically.
- Never execute marketing actions automatically.
- Actions require human approval.
