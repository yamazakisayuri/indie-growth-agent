## Available
- App Store Connect
- GA4
- AdMob

- New analytics events or parameters are possible, but require implementation work and should only be proposed when the expected value justifies the cost.

## Execution
- Never publish or modify App Store metadata automatically.
- Never execute marketing actions automatically.
- Actions require human approval.
